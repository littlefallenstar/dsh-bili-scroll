# 配置指南（给别人看的）

这个插件只有两样东西需要你亲自配：**B站登录** 和 **QQ 邮箱**。Obsidian 是可选的。

统一入口：DSH 右侧栏 →「刷B站」→ **环境与账号**。改完即时生效。

---

## 1. B站登录（必做）

点「扫码登录」→ 手机 B站 → 我的 → 扫一扫。
⚠️ 手机上确认时选**「记住我 / 长期」**那张，选 24 小时的第二天就要重扫。

登录状态存在 `~/.dsh/bili-duty/bili_credential.json`，不会上传，也不会写进日志。

---

## 2. 邮箱（推荐配，不配就只能在面板里看）

### 2.1 拿授权码（QQ 邮箱）

1. 电脑登 qq 邮箱 → 设置 → **账户**
2. 找到「POP3/IMAP/SMTP/Exchange/CardDAV 服务」→ 开启 **SMTP 服务**
3. 按提示验证后会给你一串 **16 位授权码** —— 复制它

> 授权码不是 QQ 密码，也不能登录邮箱；它只用来让程序替你发信。随时可以在同一页「删除」掉。

### 2.2 填进插件

环境与账号 → 邮箱：

- **发件邮箱**：`123456@qq.com`
- **授权码**：刚才那串（保存后输入框会清空，不会回显）
- **收件人**：空 = 发给自己；多个用逗号隔开

点「保存邮箱」，再点「发一封测试」—— 收到就通了（没收到先看垃圾箱）。

配置落在 `~/.dsh/bili-duty/mail.json`，保存时会用 icacls 收紧到只有当前用户能读。

### 2.3 每轮发什么

- **每轮跑完 → 一封总结**：这一轮推荐的几条（标题 / UP / 评分 / 一句理由 / 链接），**不叠加上一轮**
- **你点某条的「深挖」→ 单独一封该视频的笔记**，同样不叠加
- 详细笔记不在总结里，避免一封信几千字

---

## 3. Obsidian（可选，后装也能补）

### 3.1 没有 Obsidian 的人

**什么都不用做，保持关闭。** 只发邮件，功能一切正常。

### 3.2 已经有的

环境与账号 → Obsidian → 点 **「自动探测」**（会读 `%APPDATA%\obsidian\obsidian.json` 找当前打开的库）→ 点 **「试写一个」** 确认能写 → **「保存 Obsidian」**。

写出来的结构（库内，默认子目录 `B站日报`）：

```
B站日报/
  2026-10-18/
    round-0139.md      ← 01:39 那一轮的总结
    round-0410.md      ← 04:10 那轮的总结（不覆盖上一份）
    note-BV1xxxxxxx.md ← 你点「深挖」的那条视频的笔记
```

### 3.3 后装的情况

插件**不会**因为当初没配就锁死：
- 后装了 Obsidian → 回来点「自动探测」→ 保存，之后每一轮自动写
- 之前的邮件不受影响；今日列表（`~/.dsh/bili-duty/today/`）也不受影响
- 想补历史：面板「今日」里选旧日期 → 对想留的条目点「深挖」，笔记会写进库

## 4. 每个配置存在哪（卸载/迁移时用）

| 东西 | 位置 |
|---|---|
| 插件配置 / 今日列表 / 产物 | `~/.dsh/bili-duty/` |
| 邮件配置（含授权码） | `~/.dsh/bili-duty/mail.json` |
| B站登录凭证 | `~/.dsh/bili-duty/bili_credential.json` |
| 判重表 | `~/.dsh/bili-duty/seen.md` |
| Python 环境 | `~/.dsh/bili-duty/.venv/` |
| 运行日志 | `~/.dsh/bili-duty/duty.log` |

换机器 = 拷 `~/.dsh/bili-duty/`（里面有授权码，注意别公开）。

---

## 5. 常见问题

**点「装主依赖」失败**：内置镜像走清华源会 403。用阿里云：
```powershell
$env:BILI_DUTY_PIP_MIRROR='https://mirrors.aliyun.com/pypi/simple'
```
再点一次。

**收不到信**：① 授权码是不是填成登录密码了 ② QQ 邮箱 SMTP 开了吗 ③ 垃圾箱 ④ 点「发一封测试」看面板提示。

**后台那轮跑不起来**：桌面版没有全局 `dsh`，本 fork 已经处理（用 asar 里的 cli.js + `ELECTRON_RUN_AS_NODE=1`）；如果还报 `MISSING_CREDENTIAL`，说明凭据没取到，检查 `~/.dsh/.credentials.yaml`。

**稍后再看里的视频删不掉**：那是 B站 自己的规则 —— 要看到进度条末尾才会自动移除，或手动删。插件只负责往里加。
